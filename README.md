# Delicious Bites Restaurant Website

## Project Overview

This is a modern, responsive restaurant website for "Delicious Bites" - a premium burger and fast food restaurant. The website features a complete ordering system, menu display, and customer management functionality.

## Features Added/Modified

### 🔐 Enhanced Login System

- **Multi-user authentication** with different user roles (Admin, Manager, Cashier)
- **Account lockout security** after 3 failed login attempts
- **Session management** with user data storage
- **Improved UI** with modern glassmorphism design

### 🎨 Modern Design Updates

- **New color scheme** with CSS variables for consistent theming
- **Glassmorphism effects** on login form
- **Enhanced animations** and hover effects
- **Responsive design** improvements

### 🍔 Restaurant Branding

- Changed from "MOS Burgers" to "Delicious Bites"
- Updated menu item names and pricing
- Modified contact information and location
- Enhanced footer with additional information

### 📱 New Order Tracking System

- **Real-time order tracking** with visual timeline
- **Order status updates** with different stages
- **Customer information display**
- **Estimated delivery times**
- **Sample order database** with demo data

### 🌟 User Experience Improvements

- Added order tracking navigation link
- Enhanced footer with opening hours and contact info
- Improved form validation and error handling
- Better visual feedback for user interactions

## Technical Specifications

### Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with CSS Grid and Flexbox
- **JavaScript** - Interactive functionality
- **Bootstrap 5** - Responsive framework
- **Font Awesome** - Icons
- **AOS (Animate On Scroll)** - Scroll animations
